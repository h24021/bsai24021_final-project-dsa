📚 Library Management System API

RESTful API for managing books, users, borrowing, and statistics

Base URL: http://localhost:8080/api/v1

📑 Table of Contents

  • 📖 Books
  • 👥 Users
  • 📚 Borrowing & Returns
  • 📊 Statistics & Dashboard

📖 Books

GET /api/v1/books

Get all books in the library

Response (200 OK)

{
  "books": [
    {
      "bookId": 101,
      "title": "The Great Gatsby",
      "author": "F. Scott Fitzgerald",
      "isbn": "ISBN-101",
      "category": "Fiction",
      "totalCopies": 3,
      "availableCopies": 3
    }
  ]
}
GET /api/v1/books/search?query={searchTerm}

Search books by title, author, ISBN, or category

Query Parameters

query (string) Search term to match against book fields

Response (200 OK)

{
  "results": [
    {
      "bookId": 103,
      "title": "1984",
      "author": "George Orwell",
      "isbn": "ISBN-103",
      "category": "Dystopian",
      "totalCopies": 3,
      "availableCopies": 2
    }
  ]
}
GET /api/v1/books/:id

Get a specific book by ID

Path Parameters

id (integer) Book ID

Response (200 OK)

{
  "bookId": 101,
  "title": "The Great Gatsby",
  "author": "F. Scott Fitzgerald",
  "isbn": "ISBN-101",
  "category": "Fiction",
  "totalCopies": 3,
  "availableCopies": 3
}
POST /api/v1/books

Create a new book

Request Body

{
  "bookId": 111,
  "title": "New Book Title",
  "author": "Author Name",
  "isbn": "ISBN-111",
  "category": "Category",
  "totalCopies": 5,
  "availableCopies": 5
}

Response (200 OK)

{
  "message": "Book added successfully"
}
PUT /api/v1/books/:id

Update an existing book

Path Parameters

id (integer) Book ID to update

Request Body

{
  "title": "Updated Title",
  "author": "Updated Author",
  "isbn": "Updated-ISBN",
  "category": "Updated Category",
  "totalCopies": 5,
  "availableCopies": 4
}
DELETE /api/v1/books/:id

Delete a book

Path Parameters

id (integer) Book ID to delete

Response (200 OK)

{
  "message": "Book deleted successfully"
}

👥 Users

GET /api/v1/users

Get all users

Response (200 OK)

{
  "users": [
    {
      "userId": 1,
      "name": "John Doe",
      "email": "john@example.com",
      "membershipType": "Student",
      "borrowedBooks": []
    }
  ]
}
GET /api/v1/users/:id

Get a specific user by ID

Path Parameters

id (integer) User ID

Response (200 OK)

{
  "userId": 1,
  "name": "John Doe",
  "email": "john@example.com",
  "membershipType": "Student",
  "borrowedBooks": [101, 103]
}
GET /api/v1/users/email/:email

Get a user by email address

Path Parameters

email (string) User email address
GET /api/v1/users/:id/borrowed

Get all books borrowed by a specific user

Path Parameters

id (integer) User ID

Response (200 OK)

{
  "userId": 1,
  "borrowedBooks": [
    {
      "bookId": 101,
      "title": "The Great Gatsby",
      "author": "F. Scott Fitzgerald",
      "borrowDate": "2025-12-15"
    }
  ]
}
POST /api/v1/users

Create a new user

Request Body

{
  "userId": 100,
  "name": "Jane Smith",
  "email": "jane@example.com",
  "membershipType": "Faculty"
}

Response (200 OK)

{
  "message": "User added successfully"
}
PUT /api/v1/users/:id

Update an existing user

Path Parameters

Request Body

{
  "name": "Jane Smith Updated",
  "email": "jane.updated@example.com",
  "membershipType": "Staff"
}
DELETE /api/v1/users/:id

Delete a user

Path Parameters

id (integer) User ID to delete

📚 Borrowing & Returns

POST /api/v1/borrow

Borrow a book

Request Body

{
  "userId": 1,
  "bookId": 101
}

Response (200 OK)

{
  "message": "Book borrowed successfully",
  "userId": 1,
  "bookId": 101
}
POST /api/v1/return

Return a borrowed book

Request Body

{
  "userId": 1,
  "bookId": 101
}

Response (200 OK)

{
  "message": "Book returned successfully",
  "userId": 1,
  "bookId": 101
}
GET /api/v1/books/:id/history

Get borrowing history for a specific book

Path Parameters

id (integer) Book ID

Response (200 OK)

{
  "bookId": 101,
  "history": [
    {
      "userId": 1,
      "userName": "John Doe",
      "borrowDate": "2025-12-15",
      "returnDate": "2025-12-20"
    }
  ]
}
